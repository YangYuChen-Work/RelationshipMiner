# 沉浸式关系图谱工作台设计

## 目标

将当前分析结果页重构为铺满浏览器内容区的关系图谱工作台，解决中文乱码、节点过小、文字重叠、层级不清和详情查看割裂的问题。同时将数据库表与字段选择合并为可折叠的表级选择器，使用户能够快速展开字段并执行表内全选。

本次改造沿用现有 React、Zustand、D3 和 Tailwind 技术栈，不改变后端分析协议与图谱数据结构。

## 设计方向

- 页面类型：面向数据分析人员的专业图谱工作台。
- 视觉语言：深色画布、冷灰界面、单一青绿色交互强调色。
- 设计参数：变化度 5、动效 4、信息密度 7。
- 节点形式：实体卡片节点，而不是小圆点。
- 全屏含义：铺满浏览器内容区域，不调用浏览器 Fullscreen API。

## 页面结构

### 选择阶段

选择页保留产品标题和简短说明，主体改为单一的“数据范围”区域，不再将表与字段拆成两张相互割裂的卡片。

每张数据库表显示为一个可选择、可折叠的行：

- 左侧复选框控制该表是否参与分析。
- 表名旁显示字段总数或加载状态。
- 右侧下拉按钮展开或收起字段列表。
- 选中表后加载字段；加载完成后默认展开该表。
- 表头显示已选字段数量，并提供“全选字段”或“取消全选”。
- 主键与类名字段始终选中且不可取消，使用明确的“主键”和“类名”标签解释原因。
- 点击未选中表的下拉按钮时，同时选中该表、加载字段并展开；取消选择后收起字段列表。
- 达到十张表上限后，未选中的表进入禁用状态，并显示清晰的上限说明。

底部操作区显示已选表数、已选字段总数和“开始分析”按钮。按钮仅在至少选择一张表时可用。

### 分析阶段

分析进度使用与最终工作台同一视觉框架：

- 顶部显示当前阶段、阶段名称和百分比。
- 中部使用与最终画布相似的深色背景和结构化骨架屏。
- 五个分析阶段作为连续步骤展示。
- WebSocket 失败、超时或后端错误在当前页面内给出可重试提示。

### 结果阶段

结果页使用 `100dvh` 高度的沉浸式工作台：

- 顶部固定工具栏，高度约 64px。
- 主体为可缩放、可平移的 D3 SVG 图谱画布。
- 桌面端右侧详情栏宽约 360px，选中节点后常驻显示。
- 未选中节点时，右侧栏显示操作说明和图谱概览，不留空白。
- 小屏幕下详情栏改为覆盖式抽屉，可关闭后继续操作图谱。

## 顶部工具栏

工具栏包含：

- 产品标识与“关系图谱”标题。
- 节点数、关系数和当前可见关系数。
- 置信度阈值滑杆及数值。
- “适应画布”操作。
- “重新布局”操作。
- “导出 JSON”操作。
- “新分析”操作。

置信度筛选只隐藏低于阈值的边和边标签，不隐藏节点。统计区域同步展示筛选后可见的关系数量。

## 图谱渲染

### 节点

节点使用横向实体卡片，建议基础尺寸约为 168 × 64px：

- 顶部小字显示来源表。
- 主标题显示类名的最后一段；若类名为空，则显示节点 ID 的可读片段。
- 辅助信息显示关联数量。
- 左侧状态条或小型标记区分来源表；颜色保持低饱和，选中态统一使用青绿色。
- 文本使用深色画布上的高对比浅色，不再放置于小圆内部。
- 长文本省略，并通过原生标题或详情栏提供完整内容。

节点有默认、悬停、选中和弱化四种状态。悬停节点时只突出该节点及其直接相邻节点和边，不递归高亮整个连通分量，避免大型图谱中大面积同时高亮。

### 边

- 边使用低对比冷灰线，悬停或选中关系使用青绿色。
- 置信度控制边的不透明度和线宽。
- 关系标签显示在边中点附近，使用带深色底的紧凑标签，避免与连线混在一起。
- 箭头标记按节点卡片边界计算终点，避免箭头进入卡片内部。
- 多条同源同目标关系允许使用合并标签展示，不额外引入复杂曲线布线。

### 布局

D3 力导向布局使用矩形碰撞范围，节点间距以卡片尺寸而非圆半径计算。初次稳定后自动执行一次“适应画布”，确保所有节点进入可视区域。

交互包括：

- 滚轮或触控板缩放。
- 拖动画布平移。
- 拖动节点调整位置。
- 单击节点选中并更新右侧详情。
- 单击空白区域取消选择。
- “适应画布”根据当前节点包围盒缩放居中。
- “重新布局”清除节点固定位置并重启力导向模拟。

所有动画尊重 `prefers-reduced-motion`，并在组件卸载时清理 D3 simulation、定时器、ResizeObserver 和事件处理器。

## 无关系状态

当分析结果包含节点但没有关系时：

- 不显示覆盖画布中央的大型警告。
- 节点按来源表分组并采用规则网格布局，保持全部可读。
- 顶部统计区域显示“0 条关系”。
- 画布左上角显示紧凑说明：“暂未发现关系，可返回调整表或字段范围。”
- 工具栏仍提供导出和新分析操作。

当图谱没有节点时，画布显示明确空状态，并提供“新分析”按钮。

## 右侧详情栏

详情栏在工作台布局内占据固定区域，不再使用遮罩阻断画布操作。内容包括：

- 节点名称、完整 ID、来源表和关联度。
- 字段值键值表；长值允许换行或复制，不使用破坏布局的单行截断。
- 直接关联节点列表。
- 每个关联项显示关系标签、置信度和目标节点摘要。
- 点击关联项切换选中节点，并让画布聚焦该节点。

字段值为 `null` 时显示 `NULL`；对象或数组以格式化 JSON 摘要展示。

## 状态与组件边界

保持 Zustand 为跨组件状态来源，并新增必要的工作台交互状态：

- 当前选中节点。
- 当前悬停节点。
- 置信度阈值。
- 图谱布局重置请求。
- 适应画布请求。
- 小屏详情抽屉开关。

建议组件边界：

- `SelectionWorkspace`：选择阶段整体布局。
- `DatabaseTableAccordion`：单张表的选择、加载与折叠。
- `GraphWorkbench`：结果阶段整体布局。
- `GraphToolbar`：统计、筛选和工作台操作。
- `GraphCanvas`：纯图谱渲染和 D3 交互。
- `NodeDetailPanel`：选中节点详情。

现有 API 层保持不变。现有 `TableSelector` 和 `FieldSelector` 可合并或由新的选择工作区组合，具体以保持测试清晰和减少重复状态为准。

## 编码修复

当前多个前端源码与测试文件中的中文已被错误编码保存。改造时需要：

- 将受影响的可见中文、注释、错误提示和测试期望统一恢复为 UTF-8。
- 确保 `index.html` 继续声明 UTF-8。
- 不对来自后端的未知乱码做前端猜测性转码；后端响应应按 JSON UTF-8 处理。
- 通过源码扫描确保不再残留典型乱码片段。

## 可访问性与响应式

- 所有按钮具有文本或 `aria-label`。
- 折叠表头使用 `aria-expanded` 和关联区域 ID。
- 复选框保持原生控件语义。
- 节点支持键盘聚焦和 Enter/Space 选择。
- 焦点状态清晰可见。
- 工具栏在窄屏允许横向滚动或分组换行，图谱仍占据主要空间。
- 详情抽屉在移动端提供明确关闭按钮，并保持焦点可达。

## 错误、加载与降级

- 表列表和字段加载使用与最终行结构一致的骨架状态。
- 单张表字段加载失败只影响该表，可在表内重试。
- 图谱渲染异常不应丢失分析结果；显示错误提示并保留导出和新分析操作。
- `ResizeObserver` 不可用时使用初始容器尺寸完成渲染。
- 节点缺少类名、字段或关系标签时使用明确的可读回退值。

## 测试与验收

### 自动化测试

- 修复现有乱码测试数据和期望。
- 覆盖表折叠、展开和字段加载。
- 覆盖单表全选与取消全选，并验证主键和类名仍被选中。
- 覆盖达到表数量上限后的禁用状态。
- 覆盖节点单击选择和详情栏更新。
- 覆盖置信度筛选后的可见关系统计。
- 覆盖无关系和无节点状态。
- 覆盖新分析、导出与 WebSocket 错误流程。

### 视觉验收

- 1920×1080 下结果工作台铺满内容区，没有外部大面积空白。
- 20 个节点全部保持可辨认文字，不出现文字塞入圆点或明显重叠。
- 右侧详情栏不遮挡桌面端画布。
- 无关系结果仍能清晰查看全部节点。
- 1280px、768px 和移动宽度下布局可用。
- 缩放、平移、拖动、适应画布和重新布局均正常。
- 页面中不存在乱码。

## 非目标

- 不修改后端关系发现算法。
- 不增加新的图谱数据字段或数据库接口。
- 不引入 Canvas/WebGL 渲染。
- 不实现浏览器 Fullscreen API。
- 不增加图谱搜索、路径分析、节点编辑或结果持久化。
