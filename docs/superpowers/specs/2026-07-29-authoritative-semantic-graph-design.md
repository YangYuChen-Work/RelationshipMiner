# 权威结构关系与语义关系融合图谱设计

## 目标

当用户选择 `meprocess`、`meoperation`、`mestep`，以及可选的
`assembly` 后，系统必须稳定输出：

- 表与表之间的聚合关系；
- 实体数据与实体数据之间的关系；
- 数据库已经明确记录的工艺层级/物料关系；
- 大模型根据用户所选字段值补充的语义关系；
- 在大模型超时或部分失败时仍可用的节点与已确认关系。

`class_name` 不作为用户必选字段。若表中存在该列，后端自动读取并用它解析
通用关系表；前端仅将它作为表名后的辅助类型信息。

## 已确认根因

四张业务实体表没有声明可供 SQLAlchemy 发现的跨表外键。真实关系主要位于
`bom_temp_view_data`、`metargetrl` 和 `relation_id` 等通用关系表中，字段形态为
`left_id`、`right_id`、`left_class`、`right_class`。

当前分析器只使用外键、唯一字段和大模型候选判断，因此漏掉上述关系。真实库
复核得到的去重关系包括：

- `MEProcess → MEOperation`：35 条；
- `MEOperation → MEStep`：87 条；
- `MEProcess → Assembly`：41 条；
- `MEOperation → Assembly`：22 条；
- `MEStep → Assembly`：1 条。

其中 `MEOperation → Assembly` 的 22 条是三个真实关系源的去重并集：
`metargetrl` 与 `relation_id` 记录相同的 18 个实体对，`bom_temp_view_data`
另有 4 个仅该来源命中的实体对。`bom_temp_view_data` 的 19 行在来源内折叠为
4 个实体对（15 行重复），因此权威计数是 `18 + 4 = 22`，而不是单一来源的
18 条。

纯大模型路径在 180 秒内仅完成 20/400 个候选判断。超时分支又返回空节点和
空边，因此造成“没有关系”和空白图。

## 后端设计

新增独立的结构关系解析模块。它只识别数据库中实际存在、且列签名符合要求的
关系源，不把表名或 `class_name` 作为前端必填参数。

处理顺序：

1. 正常读取用户选择的实体表，并自动带出主键与 `class_name` 候选列。
2. 建立 `(class_name, obj_id) → entity_id` 索引。
3. 在已知通用关系源中查询选中实体类型之间的跨表关系。
4. 按实体对去重；多个关系源命中同一实体对时合并证据。
5. 生成置信度为 1.0 的强关系：
   - `MEProcess → MEOperation`：`包含工序`；
   - `MEOperation → MEStep`：`包含工步`；
   - 指向 `Assembly`：`关联物料`；
   - 其他类型组合：`结构关联`。
6. 大模型只处理未被结构关系覆盖的语义候选，并生成弱关系。
7. 无论大模型是否超时，最后都从已读取实体、结构关系和已完成语义判断组装图谱。

关系查询必须：

- 使用参数化 SQLAlchemy 表达式；
- 仅查询当前选择的 class 类型；
- 排除同一业务表内部关系；
- 在查询和合并阶段检查分析截止时间；
- 不向前端泄漏数据库异常详情。

## 状态与错误语义

- `complete`：结构发现和全部计划的大模型判断都完成。
- `partial`：大模型、规划或候选判断超时/部分失败，但仍返回节点和已确认关系。
- `failed`：无法读取足够数据形成图谱，或所有关系判断失败且没有可靠关系。

“完整分析未发现关系”只允许出现在真正完成、且结构关系与语义关系均为零时。
超时结果不得使用该提示。

## 图谱展示设计

图谱采用分层网络视图，不再用大面积矩形表格区域承载密集小点：

- 表节点是大尺寸锚点；
- 实体节点围绕所属表锚点分布；
- 表/实体按表类型使用稳定颜色；
- 实体节点大小随关联度增加；
- 强结构关系使用实线，语义关系使用虚线；
- 边展示 `包含工序`、`包含工步`、`关联物料`、`语义关联` 等标签；
- 保留搜索、适应画布和重新布局；
- 增加关系类型图例/筛选和“显示孤立节点”开关。

默认只布局有关联的实体节点，并显示隐藏的孤立实体数量。用户开启开关后才加载
全部孤立节点。Canvas、Web Worker、空间命中索引和语义缩放继续保留，以避免
约 7000 个节点同时布局和绘制导致浏览器及电脑卡顿。

## 验收标准

1. 三表真实数据库分析必须返回至少 35 条工艺—工序与 87 条工序—工步去重关系。
2. 加入 `assembly` 后必须返回结构物料关系，且同一实体对不重复。
3. 模拟大模型超时时，结果为 `partial`，但实体节点和结构边不为空。
4. `class_name` 不需要用户勾选，关系解析仍有效。
5. 默认图中只显示有关联实体，用户可切换显示全部实体。
6. 画面呈现表锚点、分类型颜色、关系标签与强弱线型。
7. 后端测试、前端测试、lint、构建和真实数据库端到端分析全部通过。
